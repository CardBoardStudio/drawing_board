compat: safe
title: Learn to play's Back looks back without lighting the table
---
Back in Learn to play shows an earlier step's note and says you have done it, but no longer rings a card, marks a hex or shows a drag for an action you already took. The note stays where it was, and Return to current step goes straight back. Doing the current step's action while looking back still counts, and reloading the page returns to the current step. [Learn to play](rulebook.html#learn-to-play).
